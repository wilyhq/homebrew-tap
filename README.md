# wilyhq/homebrew-tap

Homebrew tap for [wily](https://wily.bot).

```sh
brew install --cask wilyhq/tap/wily   # desktop app (updates itself after install)
brew install wilyhq/tap/wily-cli      # command-line tool
```

No release has been published yet — the cask and formula appear here with the first public
release. Binaries are downloaded from `updates.wily.bot`; this repository holds only the
manifests, updated by the release pipeline.
